# Audio Processing Pipeline: VAD + Диаризация + ASR

Пайплайн для обработки аудиозаписей на русском языке, который на выходе даёт JSON с транскрипцией, разбитой по спикерам, с таймингами на уровне слов и эмбеддингами голосов.

## Что делает пайплайн

Для каждого `.wav` файла из папки `data/` выполняется следующая последовательность шагов:

1. **VAD (Silero VAD)** — находит участки речи в аудио и отсекает тишину.
2. **Диаризация (`pyannote/speaker-diarization-community-1`)** — определяет, кто и когда говорит, и размечает сегменты по спикерам.
3. **Эмбеддинги спикеров (`pyannote/embedding`)** — строит усреднённый голосовой эмбеддинг для каждого спикера на основе его сегментов.
4. **Слияние таймингов** — результаты VAD и диаризации объединяются в единый набор сегментов речи с привязкой к спикеру.
5. **ASR (GigaAM)** — каждый сегмент нарезается во временный `.wav`-файл и распознаётся моделью GigaAM (по умолчанию `v3_e2e_rnnt`) с таймингами по словам.
6. Результат сохраняется в `results/<имя_файла>_result.json`.

## Требования

- Python 3.10+
- Желательно GPU с CUDA (пайплайн автоматически использует `cuda`, если она доступна, иначе — `cpu`)
- Аккаунт на [Hugging Face](https://huggingface.co)

## Установка

### 1. Клонирование репозитория

```bash
git clone <URL_этого_репозитория>
cd <папка_проекта>
```

### 2. Виртуальное окружение

```bash
python -m venv venv
source venv/bin/activate      # Linux/macOS
venv\Scripts\activate         # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```
### 4. Установка PyTorch с поддержкой Cuda

Установить PyTorch можно на официальном сайте: https://pytorch.org/get-started/locally/

### 5. Установка GigaAM

GigaAM не распространяется через `pip install gigaam` — согласно официальной инструкции его нужно ставить из исходников в editable-режиме:

```bash
git clone https://github.com/salute-developers/GigaAM.git
cd GigaAM
pip install -e .[torch]
cd ..
```

### 6. Установка необходимых зависимостей

Установить ffmpeg-shared версии 6, 7 или 8. Можно воспользоваться готовыми сборками: https://www.gyan.dev/ffmpeg/builds/ 

### 7. Доступ к моделям pyannote на Hugging Face

Модели диаризации и эмбеддингов — gated, то есть для их скачивания нужно один раз принять условия использования, будучи авторизованным на Hugging Face:

1. Зайдите под своим аккаунтом и примите соглашение на странице [`pyannote/speaker-diarization-community-1`](https://huggingface.co/pyannote/speaker-diarization-community-1).
2. Примите соглашение на странице [`pyannote/embedding`](https://huggingface.co/pyannote/embedding).

Без этого шага `Pipeline.from_pretrained(...)` и `Model.from_pretrained(...)` упадут с ошибкой доступа (401/403), даже если токен указан верно.


### 8. Токен Hugging Face

1. Создайте токен на странице [hf.co/settings/tokens](https://huggingface.co/settings/tokens) с правом **Read** (полных прав на запись для этого пайплайна не требуется).
2. Создайте в корне проекта файл `config.txt` и вставьте туда токен **одной строкой, без пробелов и пустой строки в конце**.


## Структура проекта

```
.
├── config.txt                  # HF-токен 
├── requirements.txt
├── data/                       # входные .wav файлы
├── results/                    # выходные *_result.json (создаётся автоматически)
├── temp_audio_segments/        # временные нарезанные сегменты (создаётся автоматически)
└── pipeline.ipynb              # основной ноутбук с пайплайном
```

## Использование

1. Положите исходные аудиозаписи в формате `.wav` в папку `data/`.
2. Откройте `pipeline.ipynb` и выполните все ячейки — функция `main()` пройдётся по всем `.wav`-файлам из `data/` и обработает их по очереди.
3. Результаты появятся в `results/` — по одному JSON-файлу на каждую запись.
